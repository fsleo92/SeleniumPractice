# Sauce Demo Selenium + Cucumber Framework

A Java/Maven training project that demonstrates the Page Object Model (POM) with
Selenium WebDriver and Cucumber. The sample flows use the live Shopify storefront
at <https://sauce-demo.myshopify.com/> and the registration markup provided in
`HomePageSource.txt` and `SignUpPageSource.txt`.

The test scenarios cover loading the home page, navigating to the Create Account
page, checking the registration controls, and entering sample data. They do not
submit the form or create a live account.

## Requirements

- JDK 8 or later
- Apache Maven 3.6 or later
- Chrome or Firefox installed
- Internet access for the storefront and first-time WebDriver/dependency downloads

Selenium 4.8.3, Cucumber 7.11.2, and WebDriverManager 5.6.3 are pinned to versions
compatible with Java 8. WebDriverManager downloads the matching ChromeDriver or
GeckoDriver when the suite starts.

## Run the tests

Run all Cucumber scenarios in Chrome (the default):

```bash
mvn clean test
```

Run in Firefox:

```bash
mvn clean test -Dbrowser=firefox
```

Run only the home-page smoke scenario:

```bash
mvn test -Dcucumber.filter.tags="@smoke"
```

The browser can also be selected by setting the `browser` system property to
`chrome` or `firefox`. Each scenario starts and closes its own browser.

## Reports

After a test run, open `target/cucumber-report.html` for the HTML report.
`target/cucumber-report.json` contains the JSON report. Both are generated by
the Cucumber runner.

## Framework notes

- **DriverFactory** selects and creates Chrome or Firefox drivers, and stores the
  driver per thread.
- **Locators** are kept separately from page behavior. The form selectors target
  input elements directly because the supplied page source reuses the input IDs
  on their surrounding `<div>` elements.
- **Page objects** contain waits and browser interactions; step definitions
  connect Gherkin steps to those page objects.
- **Scenario hooks** open the storefront before each scenario and close the
  browser afterward.
- Registration scenarios intentionally do not click **Create**, to avoid
  creating accounts or changing data on the live demo site.
